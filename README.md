## Run locally
Just open `index.html` in a browser. No build step.

Or serve:
```
npx serve .
# or
python -m http.server 8000
```

## Deploy to GitHub Pages (free)
1. Create repo `Christiniel.github.io` (or `portfolio`)
2. Push these files (`index.html`, `styles.css`, `script.js`)
3. Settings → Pages → Deploy from branch → `main` / root
4. Your site goes live at `https://christiniel.github.io/`

## Customize
- Edit name/role in `index.html` hero
- Update projects section to add new repos
- Change contact email in `script.js` → `sendMail()`
- Theme colors in `styles.css` → `:root`
